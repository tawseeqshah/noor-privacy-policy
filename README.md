Welcome to Noor — your Islamic companion for prayer, learning, reflection, and spiritual growth.

This Privacy Policy explains how Noor (“we”, “our”, or “us”) handles user information when you use the Noor mobile application.

Noor is designed with privacy and simplicity in mind.

We may collect limited information necessary to provide app functionality, including:

Device information (device type, operating system version)
App performance and crash analytics
Notification preferences
Optional microphone access (only if used by app features such as voice interactions or audio-related functionality)

Noor does not sell your personal data to third parties.

Permissions Used
Microphone Permission (RECORD_AUDIO)

Noor may request microphone access for features that require audio input or voice functionality.

Microphone data is:

Used only while actively using related features
Never sold to third parties
Not shared without user consent

Users can disable microphone permissions anytime from device settings.

Improve app stability and performance
